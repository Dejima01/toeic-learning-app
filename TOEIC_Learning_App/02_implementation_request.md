## このファイルの使い方

Claude Code に「TOEIC学習アプリ」を作ってもらうための **実装依頼書** です。
`01_app_overview.md`（全体仕様書）と画面遷移図を渡したあと、フェーズごとに本ファイルの該当セクションを Claude Code に渡してください。

## フェーズ 1: 環境セットアップ

### 依頼内容
プロジェクトの雛形を作成してください。

- **フロントエンド**: Vite + React 18 + React Router v6
- **データベース/認証**: Firebase（Firestore + Authentication）← フロントから直接呼ぶ
- **AI連携**: 中継サーバ `https://toeic-api-proxy.onrender.com/`（独自バックエンドは作らない）
- **データ投入用スクリプト**: Python（ローカル実行のみ）

### やってほしいこと
1. プロジェクトのフォルダ構成を作る
   ```
   frontend/        ← React アプリ本体
   scripts/         ← Python シードスクリプト用
   data/            ← JSONマスターデータ（すでに存在）
   ```
2. Vite + React + React Router をセットアップ
3. Firebase SDK をインストールして初期化コードを書く（`frontend/src/firebase.ts`）
4. **中継サーバ用のクライアントを作る**（`frontend/src/lib/proxyClient.ts`）
   - ベースURL: `import.meta.env.VITE_PROXY_URL`
   - 認証ヘッダー: `Authorization: Bearer ${import.meta.env.VITE_PROXY_TOKEN}`
   - 関数: `callGemini(prompt: string): Promise<string>`
     - `POST /api/gemini` に `{ "prompt": "..." }` を送り、`response` フィールドを返す
   - 関数: `warmupProxy(): void`
     - `GET /` をfire-and-forgetで呼ぶ
5. **アプリ起動時のウォームアップ ping を実装**
   - `App.tsx` の `useEffect` で起動時に1回だけ `warmupProxy()` を呼ぶ
   - 応答は待たず、エラーは無視する（fire-and-forget）
   - 目的: Render の無料プランがスリープしている場合に起こすため
6. `.env.example` を作る（中身は `01_app_overview.md` の第9章の通り）
7. `data/seed_firestore.py` を `scripts/seed_firestore.py` に配置
8. `frontend/public/badges/` フォルダを作る（バッジ画像をあとから入れる用）
9. `.gitignore` に `serviceAccount.json` と `.env*` を必ず追加する
10. README に開発サーバー起動手順とシードスクリプト実行手順を書く

### 参照画像
なし（環境構築のみ）

### 完了の目安
- `npm run dev` でフロントが起動し、Hello World が表示される
- ブラウザの DevTools の Network タブで、起動時に中継サーバへの ping が走っているのが見える
- `scripts/seed_firestore.py` が配置されている

## フェーズ 7: ランク認定テスト

### 依頼内容
ユーザーの実力を測るテストを作ってください。

### やってほしいこと
1. **出題ロジック**
   - 全30問（前半15問: 単語 / 後半15問: 文法）
   - 600/750/900 点台から各 5問 × 2分野 = 30問をランダム抽出
   - 単語問題は「英単語 → 4択で意味を選ぶ」形式
   - 不正解の選択肢3つは同レベルの他単語の意味からランダム
2. **問題画面**
   - 選択肢タップで外枠が黒く（同時に他の選択肢の枠は外す）
   - 「テストを終了する」ボタンで解説画面へ
3. **解説画面**
   - 正解の選択肢の外枠を赤に
   - 自分の選択した選択肢の外枠を黒に（正解なら赤一致）
   - 問題横に 〇/× を表示
   - 「結果を見る」ボタンで結果画面へ
4. **結果画面**
   - 単語/文法 それぞれ 15問中の正解数を表示
   - スコア計算: 600=20点/問, 750=35点/問, 900=44点/問
   - 600/750/900点以上で ブロンズ/シルバー/ゴールド バッジを表示
   - バッジは Firestore に保存（より高いバッジでのみ更新）
   - ホームへ戻るボタン

## フェーズ 8: AIチャットボット

### 依頼内容
中継サーバ `https://toeic-api-proxy.onrender.com/` 経由で動く画面内完結型チャットボットを作ってください。

### 前提
- 中継サーバの認証: `Authorization: Bearer 2442-dev-toeic`
- フェーズ1で作った `frontend/src/lib/proxyClient.ts` の `callGemini()` を使う
- 中継サーバはストリーミング非対応 → 応答は一括で返る
- システムプロンプト: 「TOEIC満点レベルの優秀なパーソナルコーチ」
- マルチターン対応は **フロント側で履歴を整形してプロンプトに含めて送る**
  （中継サーバ側で履歴管理はしない）

### やってほしいこと
1. **チャット用 API ラッパー関数**
   - `proxyClient.ts` 内に `sendChatMessage(history, newMessage): Promise<string>` を実装
   - 履歴 + 新規メッセージを1つのプロンプト文字列に整形して `callGemini()` に渡す
   - プロンプト整形例:
     ```
     あなたはTOEIC満点レベルの優秀なパーソナルコーチです。
     英語学習者の質問に専門用語を噛み砕いた簡潔な日本語で回答してください。

     これまでの会話:
     ユーザー: ...
     AI: ...

     新しい質問:
     ユーザー: {newMessage}
     AI:
     ```
2. **React 側コンポーネント** (`ChatBot.tsx`)
   - 単語モード、文法モード、復習問題一覧の右上ボタンから起動
   - ポップアップ形式のチャットウィンドウ
   - 送信中は **「考え中…」ローディング表示**（ストリーミングではないので一括表示）
   - 会話履歴はコンポーネント State でのみ保持
   - **画面遷移時に履歴をクリア（Firestore 保存はしない）**

### 参照画像
- `15_review_list_chatbot.png` … チャットボット表示の例（吹き出し）
- 単語/文法/復習画面の右上の吹き出しボタン位置 → `10_word_mode_chapter.png`, `12_grammar_mode_chapter.png`, `13_review_list.png`

### 完了の目安
- 3つの学習画面でチャットボットが起動する
- 送信 → 「考え中…」 → 回答が表示される一連の流れが動く
- 過去の会話を踏まえた回答ができる（同じ質問の答えを引き継げる）
- 画面を出ると会話履歴が消える（Firestore には何も残らない）
