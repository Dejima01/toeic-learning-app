## 1. アプリ概要

- **アプリ名**: TOEIC学習アプリ(仮)
- **目的**: TOEICの点数向上を目指すための学習Webアプリ
- **ターゲットユーザー**: 隙間時間にTOEIC学習をしたい人、高得点を目指す人
- **プラットフォーム**: Webアプリ(モバイルファースト・レスポンシブ対応)

## 2. 技術スタック

### フロントエンド
- **React 18+**(Vite で作成)
- **React Router v6**(画面遷移)
- **状態管理**: React Context API + `useState` / `useReducer`
  (Redux などは導入しないシンプル構成)
- **スタイリング**: CSS Modules または Tailwind CSS

### バックエンド
- **独自バックエンドサーバーは作らない**（フロントエンドから直接、外部サービスを呼ぶ構成）
- ※ Node.js は React の開発環境(Vite/npm)として使うのみ

### データベース・認証
- **Firebase Authentication**(メール/パスワード認証) … フロントの Firebase SDK から直接利用
- **Firestore**(ユーザーデータ、復習マーク、バッジ情報) … フロントの Firebase SDK から直接利用
- アクセス制御は **Firestore セキュリティルール** で行う
- 問題マスターデータの格納先は将来的に別DB(例: PostgreSQL)へ移行する可能性あり

### AI連携（中継サーバ経由）
- **中継サーバ URL**: `https://toeic-api-proxy.onrender.com/`
- **認証ヘッダー（全リクエスト必須）**: `Authorization: Bearer 2442-dev-toeic`
- **モデル**: Gemini 1.5 Flash（中継サーバが内部で呼び出す）

#### エンドポイント仕様
| 用途 | メソッド | パス | 備考 |
|---|---|---|---|
| 起動確認（ヘルスチェック） | GET | `/` | ウォームアップ ping 用 |
| Gemini呼び出し（チャット・例文生成共通） | POST | `/api/gemini` | JSON 送信 |

- **リクエストボディ形式**: JSON（プロンプトを送る）
- **レスポンス形式**: `{ "response": "回答用文字列" }`
- **ストリーミング**: 非対応（応答は一括で返る）
- チャットも例文生成も**同じエンドポイント**を使い、プロンプトで出力形式を制御する

#### 通信フロー
```
1. React アプリが POST /api/gemini にリクエスト送信
   ヘッダー: Authorization: Bearer 2442-dev-toeic
   ボディ: { "prompt": "..." }（プロンプト文字列）
2. 中継サーバが Gemini 1.5 Flash を呼び出す
3. 中継サーバが { "response": "..." } を返す
4. React アプリが画面に表示
```

#### ウォームアップ（重要）
- 中継サーバは **Render の無料プラン** のため、一定時間アクセスがないとスリープ（コールドスタート）する
- スリープからの復帰には **約30〜60秒** かかる
- **対策**: アプリ起動時（ログイン画面表示時）に中継サーバへ「ping」リクエストを送ってウェイクアップさせる
  - ユーザーが学習画面に進む頃にはサーバーが起きている状態にする
  - ping は単純な GET リクエストでOK（応答待ちは不要、fire-and-forget）

### デプロイ環境(想定)
- フロントエンド: **Firebase Hosting** または Vercel
- 中継サーバ: **すでに Render にデプロイ済み**

### セキュリティに関する注意（MVPでは許容）
- Bearer トークン `2442-dev-toeic` はフロントエンドのコード/環境変数に含まれるため、ブラウザの開発者ツールから誰でも見えます
- MVP（開発用トークン）なので許容しますが、**本番リリース時はトークンをより安全な経路で扱う**（例: Firebase Functions を経由させる等）必要があります

### 3.3 単語モード

#### レベル分け・章構成
- **600点台 / 750点台 / 900点台** にレベル分け
- 1章 = 50単語

| 区分 | 各レベルの単語数 | 各レベルの章数 | 合計単語数 |
|------|----------------|--------------|-----------|
| MVP(直近目標) | 300単語 | 6章 | 900単語 |
| 最終目標 | 1,000単語 | 20章 | 3,000単語 |

#### 単語カードの表示項目
1つの単語カードに以下を表示:
1. 英単語(見出し語)
2. 英語の例文
3. 英単語の和訳および品詞
4. 例文の和訳
5. 派生語・関連語(名詞形、形容詞形、対義語など)

#### 機能1: 例文リロード機能
- 単語ごとにリロードボタンを設置
- 押すと Gemini API で英語例文+和訳を生成
- **例文+和訳は2種類生成し Firestore に保存**(初回のみ)
- リロードボタンを押すごとに **2種類を交互に表示**(API再呼び出しは不要)

#### 機能2: 和訳の表示/非表示トグル(暗記シート機能)
- 章を開いた初期状態: 「和訳・派生語」部分が**青いカバー**で隠れている
- カバーをタップ → 和訳が表示
- 再度タップ → カバーが復活して隠れる

#### 機能3: 復習マーカー機能(黄色ハイライト)
- 単語の横にある「復習ボタン」をタップ → 英単語と例文の背景が**黄色に変化**
- 再度タップで元の色に戻る(トグル)
- **データ永続化**: マーカー状態は Firestore に保存され、再起動後も維持
- 復習問題一覧と連動

---

### 3.4 文法モード(TOEIC Part5形式 / 4択穴埋め)

#### レベル分け・章構成
- 600点台 / 750点台 / 900点台
- 1章 = 15問

| 区分 | 各レベルの問題数 | 各レベルの章数 | 合計問題数 |
|------|---------------|--------------|-----------|
| MVP(直近目標) | 75問 | 5章 | 225問 |
| 最終目標 | 300問 | 20章 | 900問 |

#### UI挙動
- **タップ時のフィードバック**: 選択肢を押すと1秒間ボタンの外枠が黒く太くなる
- **解説の自動オープン**: 章入室直後は解答・解説が青いカバーで隠れている。**選択肢を1つでも押した瞬間にカバーが外れる**
- 章を出ると未解答状態に戻り、カバーが復活する

#### 復習マーカー機能(自動 + 手動)
- **自動ハイライト**: 不正解の選択肢を押すと、自動的に問題文の背景が黄色になる
- **手動ハイライト**: 問題の横の「復習ボタン」でもトグル可能(正解したが復習したい問題用)
- **データ永続化**: Firestore に保存され、再起動後も維持

### 3.5 ランク認定テスト

#### 出題仕様
- 全30問(前半15問: 単語問題 / 後半15問: 文法問題)
- 各レベルからランダム出題:

| レベル | 単語問題 | 文法問題 |
|--------|---------|---------|
| 600点台 | 5問 | 5問 |
| 750点台 | 5問 | 5問 |
| 900点台 | 5問 | 5問 |

- 単語問題は「英単語 → 4択で意味を選ぶ」形式
- 不正解の選択肢3つは、同レベルの他の単語の意味からランダム抽出

#### UI挙動
- 選択肢を押すとボタンの外枠が黒くなる
- 別の選択肢を押すと、前の選択肢の枠が消え、新しい選択肢の枠が黒くなる
- 「テストを終了する」ボタンで**解説画面**へ遷移

#### 解説画面
- 正解の選択肢の外枠が **赤** になる
- 自分が選択した解答の外枠が **黒** になる
- 自分の解答が正解の場合、外枠は **赤(正解と一致)**
- 問題の横に **〇/×** を表示
- 「結果を見る」ボタンで結果画面へ

#### 結果画面 / スコア計算

| レベル | 問題数 | 1問あたりの点数 |
|--------|------|---------------|
| 600点台 | 10問 | 20点 |
| 750点台 | 10問 | 35点 |
| 900点台 | 10問 | 44点 |

- 単語/文法それぞれ15問中何問正解か表示
- 合計点に応じてバッジを表示:
  - **600点以上 750点未満 → ブロンズバッジ**
  - **750点以上 900点未満 → シルバーバッジ**
  - **900点以上 → ゴールドバッジ**

#### バッジの永続化
- 獲得済みバッジはホーム画面に常時表示
- **より高いバッジを獲得した場合のみ更新**(下位のバッジでは上書きしない)
- Firestore に保存

### 3.6 復習問題一覧

- **単語モードで黄色マークが付いた単語**を一覧表示
- 各行に「英単語 + 意味」のセットを表示
- 行をタップ → ウィンドウで以下を表示(単語モードと同じ項目):
  1. 英単語
  2. 英語の例文
  3. 和訳・品詞
  4. 例文の和訳
  5. 派生語・関連語
- ウィンドウ内でも例文リロード機能を使用可能
- 初期状態では英単語と例文の背景が黄色
- ウィンドウ内の復習ボタンを押す → 黄色解除(単語モードと連動)
- ウィンドウ右上の **×** で閉じる
  - 閉じた際に黄色が解除されていれば、一覧からその単語は消える

> 補足: 文法問題の復習一覧も同様に必要かどうか、要検討。
> 現状の仕様書では単語のみ記載されているため、必要であれば追記してください。

### 3.7 AIチャットボット

#### 機能概要
解説を読んでも理解できない時に、AIとリアルタイムに会話して疑問点を解消する機能。

#### 起動箇所
- 単語モードの暗記画面(右上の吹き出しボタン)
- 文法モードの問題演習画面(右上の吹き出しボタン)
- 復習問題一覧の詳細画面(右上の吹き出しボタン)

#### システム要件
- **LLM**: Gemini 1.5 Flash(Flask経由で呼び出し)
- **応答形式**: **ストリーミング(Streaming)** でリアルタイム出力
- **システムプロンプト**: 「TOEIC満点レベルの優秀なパーソナルコーチ」として、専門用語を噛み砕いた簡潔な解説を行う

#### 状態管理(画面内完結型マルチターン)
- **画面内では履歴を保持**: ReactのState(配列)に会話履歴を保持し、Flask経由でGeminiの `history` に乗せて送信
- **画面遷移時にクリア**: 他の画面へ遷移(コンポーネントのアンマウント)した瞬間に React の会話 State は自動クリア
- **Firestore へのログ保存は一切行わない**(完全な使い捨て)

## 5. Firestore データ構造

### users コレクション

```
📂 users
 ┗ 📄 {UID}
     ┣ 📝 email: string
     ┣ 📝 rank_score: number        // ランク認定テスト最高スコア
     ┣ 📝 badge: "bronze" | "silver" | "gold" | null
     ┃
     ┣ 📂 word_bookmarks            // 単語の復習マーク
     ┃   ┗ 📄 {questionId}
     ┃       ┗ 📝 added_at: timestamp
     ┃
     ┗ 📂 grammar_bookmarks         // 文法問題の復習マーク
         ┗ 📄 {questionId}
             ┣ 📝 added_at: timestamp
             ┗ 📝 source: "auto" | "manual"   // 自動or手動
```

> 登録日時昇順で復習一覧に表示

### word_questions コレクション(単語マスターデータ)

```
📂 word_questions
 ┗ 📄 {questionId}  例: q_word_001
     ┣ 📝 word: string                  // "accommodate"
     ┣ 📝 meaning: string               // "収容する"
     ┣ 📝 part_of_speech: string        // "verb"
     ┣ 📝 level: 600 | 750 | 900
     ┣ 📝 chapter_num: number
     ┃
     ┣ 📦 example_sentences: [          // 例文を2種類保持
     ┃     { sentence: string, translation: string },
     ┃     { sentence: string, translation: string }
     ┃   ]
     ┃
     ┗ 📦 derivatives: [
           { part: "noun", word: "accommodation", meaning: "宿泊施設" },
           { part: "adj",  word: "accommodating", meaning: "親切な" }
         ]
```

### grammar_questions コレクション(文法問題マスターデータ)

```
📂 grammar_questions
 ┗ 📄 {questionId}  例: q_grammar_001
     ┣ 📝 question_text: string         // 空欄を含む英文
     ┣ 📝 choices: [string, string, string, string]
     ┣ 📝 correct_index: number         // 0〜3
     ┣ 📝 explanation: string           // 日本語解説
     ┣ 📝 translation: string           // 全文の和訳
     ┣ 📝 level: 600 | 750 | 900
     ┗ 📝 chapter_num: number
```

> 問題マスターデータは将来 Firestore 以外の DB に移行する可能性あり

## 6. AI(Gemini)プロンプト条件

両方とも **POST /api/gemini** を使用。プロンプトの文面で挙動を切り替えます。

### 6.1 単語の例文リロード機能
- **プロンプト要件**:
  - TOEICで頻出するビジネスシーン
  - 単語の品詞と意味に沿った例文
  - 「JSONのみで返してください。説明や前置きは一切不要です」と明示する
  - 出力指定例: `{"sentence": "...", "translation": "..."}` の JSON 文字列のみを返す
- 中継サーバは JSON 文字列を `response` フィールドに入れて返してくるので、フロント側で `JSON.parse(response)` する

### 6.2 AIチャットボット
- **応答形式**: 非ストリーミング（一括レスポンス）
- **マルチターン対応**: 中継サーバが履歴管理しない場合、フロント側で会話履歴を組み立ててプロンプト全体として送る
  - 例: 「以下が過去の会話です。\nユーザー: ...\nAI: ...\nユーザー: ...\nAI: 」のように整形
- **システムプロンプト(例)**:
  > あなたはTOEIC満点レベルの優秀なパーソナルコーチです。
  > 英語学習者の質問に対して、専門用語を噛み砕いた簡潔な日本語で回答してください。
  > 必要に応じて例文を交えてください。

> ※ ストリーミング非対応のため、回答中はローディング表示（「考え中…」）を出すこと
